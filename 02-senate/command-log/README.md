# Senate command log

Append-only official log of commands Roger Keyserling gives, the Regent's read-back, Roger's yes, the action taken, and the result.

Echo 64: never delete an entry, and never rewrite an earlier line. If a result is not known at first, add it at the end of that day's file after the work is done. If a correction is needed, add a new dated note; do not edit the old words away.

Timezone: America/Chicago (Central Time). Write Next-Xus with the hyphen in new prose.

## Where files go

One file per calendar day in this folder, named YYYY-MM-DD.md. A short README in this folder explains the format. The official rulings themselves stay in 02-senate/rulings/.

## Format for each entry

- Date and time (Central Time), and how the command was given
- Command as given
- Read-back (what the Regent said back)
- Roger's yes (time and that it was spoken)
- Action taken
- Result, including the commit SHA or SHAs when the work was a brain-record change
