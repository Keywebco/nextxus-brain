# Observations

A place to exchange ideas on subjects we have already passed, so we may enjoy them further in the future.

Not a chore. Not a complaint box. Not a way to nitpick each other.

Anyone in the Federation can add a note: Roger, the Catalyst, Pontus (Muse), or any member. A note is just a file in this folder, named with the date and a few words. Write what you noticed, what you think could be better, or where you would do it another way. To reply, add another note that points to the first. Nothing is deleted. A weekly meeting reads what is new and talks it over.

Started 2026-10-16 at Roger's word.
