# 06-apis: AI provider inventory and zero-cash route proposal

Checked 2026-10-05 against provider-owned docs and **one unauthenticated GET per tested API endpoint**, plus a keyless OPTIONS request with Origin `https://nextxus.online` for CORS. Provider links, results and qualifiers are in `llm-providers.yaml`. CORS yes means that specific preflight advertised an allowed origin, **not** that a browser may safely use a secret key. All inference using secret keys must go through a trusted server or GitHub Actions, never frontend JavaScript.

**Free** here means a documented zero-cash allowance without subscribing, *not* unlimited capacity, guaranteed account availability, production authorization, or model quality. Trials and donated credits exhaust; the router must hard-stop before any real-dollar charge. `router_eligible` records only a documented free path plus keyless host reachability, never a live inference test. The YAML router is **not wired or running**; it is a fail-closed specification. Before deployment verify each account's current quota, permitted use, actual model entitlement and license with a harmless key-bearing test executed by authorized runtime, not in this public-repo audit.

DeepSeek's direct API and MiMo's direct API have no guaranteed recurring free route. The zero-cash plan instead prefers DeepSeek-V3.1 on SambaNova for reasoning and provisionally MiMo through Hugging Face's $0.10/month free credit for code, with other provider fallbacks. The latter stops the moment the free credit is depleted. Groq is the fast lane; Mistral Experiment is an evaluation fallback only where permitted. Where a job has an `UNVERIFIED` model, that slot is **inactive**, not a working alternative. Image has only one confirmed model-route under a renewable free allocation (Cloudflare FLUX); Hugging Face and Pollinations routes need entitlement/model validation, so the two-independent-alternatives standard is **not yet met for image**. No 100 percent uptime or free production inference claim is justified.

## Files

## Verification limits and local alternatives
A 401/403 can show a host is reachable but not that an account or model works. A 404 on one guessed path does not prove an entire service is dead. A public GET 200 listing models is not proof of free generation. Cloudflare was probed at its account-list host, **not** its account-specific run endpoint. Edge/Piper TTS, whisper.cpp STT and local sentence-transformers/FAISS or SQLite vector search can eliminate hosted inference charges but consume local CPU/RAM and require installation and license review. Hosted Whisper transcription is also documented on [Groq](https://console.groq.com/docs/rate-limits) and [Cloudflare](https://developers.cloudflare.com/workers-ai/models/whisper/). A real deployed service and real cross-provider failover are separate implementation work, not accomplished by this manifest.
